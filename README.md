# Breast-cancer-analysis
Breast cancer bioinformatics analysis using TCGA, GEPIA, Cytoscape, and Python
## Overview
This repository contains the computational workflow from my M.Sc. Biotechnology dissertation project focused on breast cancer bioinformatics 

The study explored the mechanistic insights of Tamoxifen and D-limonene using computational biology tools.

## Objectives
- Identify potential therapeutic targets in breast cancer
- Analyse protein- protein interaction networks
- Perform molecular docking analysis
- Study gene expression and survival trends
- Visualise computational biology workflows

## Tools & databses used
- SwissTargetPrediction
- STRING
- Cytoscape
- GEPIA
- CB-Dock2
- PyMOL
- miRNet
- TargetScan

## Workflow
1. Target prediction of compounds
2. Common targets identification between Tamoxifen and D-limonene
3. Protein-protein interaction analysis
4. Hub- gene analysis using Cytoscape
5. Molecular docking studies
6. Gene expression analysis
7. Survival analysis
8. Validation

## Key Findings
- ESR1, ESR2, PGR, AR, and CYP19A1 were identified as important target
- Network analysis highlighted key hub genes associated with breast cancer
- Gene expression analysis revealed significant ESR1 expression patterns
- Combination therapy showed reduced breast cancer cell viability.
